# manifest.json — формат

Массив объектов-слайдов. Каждый слайд:

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `kind` | string | да | Один из: `launch`, `starfield`, `planet`, `crash`, `rescue`. |
| `text` | string | да | Текст, который произносится голосом и выводится баннером. На русском. |
| `duration` | number | нет | Минимальная длительность слайда в секундах. Если меньше длины озвучки + 1с, увеличивается автоматически. |

## Полный пример

```json
[
  {
    "kind": "launch",
    "text": "Поехали! Запускаем миссию тестирования Todo приложения."
  },
  {
    "kind": "starfield",
    "text": "Развёрнуто двадцать пять API тестов и шестнадцать end-to-end сценариев."
  },
  {
    "kind": "crash",
    "text": "Внимание! Обнаружена угроза: контракт ошибок API расходился с устаревшим шаблоном тестов."
  },
  {
    "kind": "rescue",
    "text": "Угроза устранена. Тесты обновлены под фактический контракт, скилл и AGENT обновлены."
  },
  {
    "kind": "planet",
    "text": "Все находки задокументированы и готовы к коммиту."
  },
  {
    "kind": "launch",
    "text": "Миссия выполнена. До новых встреч!"
  }
]
```

## Советы по тексту

- Короткие фразы по 8–15 секунд каждая.
- Цифры пишите словами («двадцать пять»), а не «25» — `say` иногда читает чисто числом без падежа.
- Латинские слова (API, JSON) `say` читает по-английски — это нормально.
- Длинные пути и куски кода в текст не вставляйте — звучит ужасно. Подытоживайте словами.

## Длительность всего ролика

≈ сумма длительностей слайдов. Для ~2 минут — 6–8 слайдов по 12–18 секунд.
